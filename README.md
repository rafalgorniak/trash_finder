# 🗑️ Trash Finder

Trash Finder is a mobile application that helps people discover useful items others have left near public trash bins. Instead of letting valuable things go to waste, users can share, find, and reuse items within their local community.

---

## 🚀 Overview

Trash Finder allows users to:

* 📍 Mark a location on the map where they left an item
* 📸 Upload a photo of the item
* 📝 Add a short description
* 🔔 Notify nearby users about newly available items
* 🔐 Create an account and securely log in

The goal is to promote **sustainability**, **reuse**, and **community sharing**.

## 📱 How It Works

1. User logs into the app
2. Finds an item worth sharing
3. Opens the map and selects a location
4. Uploads a photo and description
5. Other users nearby receive a notification
6. Someone can go and pick up the item

## 📦 Installation

```bash

# Go into the project folder
cd trash_finder

# Install dependencies
npm install

# Start the development server
npx expo start
```
